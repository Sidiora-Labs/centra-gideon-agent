# Gideon identity assets

The active mark is a geometric G in a blue-to-teal gradient. Its vector source is [apps/console/public/gideon.svg](../../apps/console/public/gideon.svg). The filled application icon is [apps/console/public/icons/icon.svg](../../apps/console/public/icons/icon.svg), with a dark background.

| Asset | Format and use |
| --- | --- |
| [gideon-mark.svg](gideon-mark.svg) | Transparent vector mark, also used in the repository README |
| [gideon-mark.png](gideon-mark.png) | 512 × 512 application icon with a dark background |
| [gideon-mark-192.png](gideon-mark-192.png) | 192 × 192 application icon with a dark background |
| [avatar.png](avatar.png) | 512 × 512 copy of the application icon for an avatar slot |

The PNG files are copies of the current console icons under `apps/console/public/icons`. Keep the documentation copies aligned when those application assets change. These files are local assets; their presence does not imply publication to an organization profile, a public site, or a release service.
