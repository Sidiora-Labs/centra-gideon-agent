# Gideon mobile shell

A Capacitor shell that opens the gateway's served `/#/companion` route. The bootstrap
under `www/` asks for a gateway address and remembers it; the main product UI is served
by the chosen gateway rather than bundled as a second copy of the console.

## Layout

| Path | Responsibility |
|---|---|
| `capacitor.config.json` | Native WebView configuration, navigation allowlist, and inset settings. |
| `www/index.html`, `www/bootstrap/` | Address-entry screen and startup wiring. |
| `www/connection/` | Address validation, saved endpoint registry, and pairing handoff. |
| `www/platform/safe-area.mjs` | Applies resolved safe-area values to the bootstrap screen. |
| `test/` | Node tests for shell contracts. |
| `assets/`, `store/` | Asset inputs and release declaration material requiring maintainer review. |

Native iOS and Android project directories are generated by Capacitor. `www/` uses
plain modules; it does not compile a separate console UI.

## Address, session, and navigation

No `server.url` is baked into the current config. The bootstrap validates the selected
address, remembers its endpoint, and navigates to the companion page. A scanned pairing
link is handed to the gateway's own pairing page, allowing the resulting HttpOnly session
cookie to live in the WebView's cookie jar. The registry stores addresses and endpoint
metadata, not an owner token.

The current `allowNavigation` list admits loopback, selected private-network patterns,
`.local`, and `.ts.net` names. It is not `*`. The matching address rules are in
`www/connection/address.mjs`. A public reverse-proxy host is not automatically admitted:
review and change both policies deliberately if your deployment requires one.

The bootstrap remembers a selected endpoint. It does not itself implement the desktop's
full multi-gateway switcher. Served-page reconnect and authentication remain gateway
contracts. A network error is not permission to discard other devices' credentials or
bypass the destination checks.

## Safe areas and notifications

The native configuration sets `ios.contentInset` and Android edge-to-edge margin handling.
The bootstrap also resolves CSS safe-area values for its own layout. These declarations
need device verification; a source test cannot show how a native WebView renders beneath
system bars or a cutout.

The package includes the Capacitor push-notifications dependency. Dependency presence
alone does not establish native registration, remote delivery, or an OS banner. Review
and test the actual notification integration and store disclosures before release.

## Development

From the repository root, install workspace dependencies and run the Node checks:

```sh
npm ci
npm run test:mobile
```

The actual workspace name is `gideon-mobile`. Prepare the console's
`THIRD_PARTY_NOTICES.txt` through the normal console build before commands that copy it
into `www/`; `sync`, build, and the `cap` lifecycle use that notice file.

Native project commands are:

```sh
npm run add:ios --workspace gideon-mobile
npm run add:android --workspace gideon-mobile
npm run sync --workspace gideon-mobile
npm run open:ios --workspace gideon-mobile
npm run open:android --workspace gideon-mobile
```

Native builds require the current Capacitor platform toolchain: Xcode/macOS for iOS,
and the applicable Android SDK/JDK/Gradle environment for Android. See `package.json`
for build scripts. Check generated project paths under `apps/mobile/`; these commands
do not generate a top-level `mobile/` directory.

For a local gateway, explicitly bind its network interface and keep authentication
enabled. `make serve` uses loopback by default; it does not automatically expose the
runtime to a phone. Follow the [companion guide](../../docs/guides/COMPANION_APPS.md)
and [remote access guide](../../docs/guides/REMOTE_ACCESS.md).

Packaging, signing, icons, store declarations, and device qualification are separate
from the Node checks. Review the generated native project and platform release requirements before distribution.
This document does not establish published iOS or Android artifacts.
